# 玉米GoldenBraid2.0表达载体构建及遗传转化完整实验流程 SOP

**物种：** Zea mays（玉米，二倍体，2n=20）  
**系统：** GoldenBraid2.0  
**转化策略：** 幼胚基因枪法（首选）或农杆菌介导稳定转化（Agrobacterium-mediated immature embryo transformation）  
**验证策略：** 稳定遗传转化（PCR鉴定+qPCR定量）→ T1代纯合筛选  
**文件版本：** v1.0 | 日期：2026-04-06

## Step 2：单基因表达载体构建（常用于单基因表达验证）
2.1 载体选择：推荐pCAMBIA系列表达载体，CaMV35启动子，为植物常用表达载体。

2.2 标签选择：根据实验需求添加eGFP、GUS、3xflag等。

2.3 载体构建流程：
（1） 基因克隆及PCR产物纯化，参考胶回收纯化试剂盒说明书进行；
（2）pCAMBIA系列载体单酶切线性化，参考单酶切说明书进行；
（3）一步克隆法构建重组表达载体，参考一步克隆试剂盒说明书进行；
（4） 转化_E.coli_感受态细胞；
（5）单克隆鉴定及测序；
（6）质粒提取，用于农杆菌感受态细胞转化。

## Step 3：玉米稳定遗传转化

### 3.1 方法选择
|     |     |     |     |
| --- | --- | --- | --- |
| **方法** | **优点** | **缺点** | **适用情况** |
| **基因枪法（首选）** | 不受基因型限制，操作灵活 | 多拷贝整合率高，需专用设备 | 大多数玉米品系 |
| **农杆菌法** | 单拷贝整合率高，转化效率较高 | 受基因型限制，需优化 | Hi-II、B104等易转化品系 |

**推荐：** 对于大多数实验室，优先使用 **农杆菌介导法**（Hi-II品系，转化效率高，单拷贝整合率高）；若使用其他品系，可选择基因枪法。

### 3.2 材料准备
- **菌株（农杆菌法）：** A. tumefaciens EHA101（含过表达载体）
- **玉米品系：** Hi-II（A×B杂交，农杆菌转化首选）、B104、B73
- **外植体：** 授粉后9-11天的幼胚（直径1.5-2 mm）

### 3.3 培养基配方（农杆菌法）
|     |     |     |
| --- | --- | --- |
| **培养基** | **成分** | **用途** |
| 侵染培养基（IM） | MS液体 + 68.4 g/L 蔗糖 + 36 g/L 葡萄糖 + 200 μM AS，pH 5.2 | 农杆菌侵染 |
| 共培养基（CCM） | N6盐 + 2 mg/L 2,4-D + 0.7 g/L L-脯氨酸 + 68.4 g/L 蔗糖 + 200 μM AS + 0.8%琼脂，pH 5.8 | 共培养 |
| 愈伤诱导/筛选培养基（CIM） | N6盐 + 2 mg/L 2,4-D + 0.7 g/L L-脯氨酸 + 30 g/L 蔗糖 + 500 mg/L Cefotaxime + 5 mg/L Bialaphos + 0.8%琼脂，pH 5.8 | 愈伤筛选 |
| 分化培养基（DIM） | MS盐 + 0.5 mg/L BAP + 0.025 mg/L 2,4-D + 500 mg/L Cefotaxime + 3 mg/L Bialaphos + 0.8%琼脂，pH 5.8 | 芽分化 |
| 生根培养基（RM） | MS盐 + 1 mg/L NAA + 0.8%琼脂，pH 5.8 | 生根  |

### 3.4 农杆菌制备（农杆菌法）
1.  将含目标基因的过表达载体的EHA101划线至含抗生素的YEB平板：
    - 利福平（Rifampicin）：25 μg/mL
    - 载体抗生素（如卡那霉素：50 μg/mL）
2.  28°C培养2天
3.  挑单菌落接种至5 mL YEB液体培养基，28°C过夜
4.  转接至50 mL YEB，培养至OD₆₀₀ = 0.35-0.45
5.  4000 rpm离心10 min，弃上清
6.  用侵染培养基重悬至OD₆₀₀ = 0.35-0.45
7.  室温静置30 min（活化vir基因）

### 3.5 幼胚获取与侵染（农杆菌法）
**Day 0 — 幼胚获取：**
1.  选取授粉后9-11天的玉米穗（幼胚直径1.5-2 mm）
2.  表面消毒：
    - 70%乙醇：1 min
    - 50% NaClO（含0.1% Tween-20）：20 min
    - 无菌水洗涤5次
3.  在超净工作台中剥取幼胚（盾片朝上）
4.  将幼胚转移至侵染培养基（含菌液）
5.  室温侵染5 min，轻柔摇动
6.  用无菌滤纸吸干多余菌液
7.  将幼胚（盾片朝上）放置于CCM培养基
8.  25°C，黑暗，共培养3天

### 3.6 愈伤筛选与分化
**Day 3 — 转移至筛选培养基：**
1.  用含500 mg/L Cefotaxime的无菌水洗涤幼胚3次
2.  用无菌滤纸吸干，转移至CIM培养基
3.  28°C，黑暗培养
4.  每2周继代一次（转移至新鲜CIM培养基）
5.  培养4-6周，观察愈伤组织生长

**分化（约3-4周）：**
1.  将筛选阳性愈伤转移至DIM培养基
2.  28°C，16 h光照/8 h黑暗培养
3.  约2-3周后可见绿色芽点出现

### 3.7 基因枪法操作要点（备选）
**载体准备：**
- 将质粒包被至金粉（0.6 μm）或钨粉（0.7 μm）
- 金粉:质粒 = 1 mg:5 μg（每次轰击）
- 包被方法：CaCl₂/亚精胺沉淀法

**轰击参数（PDS-1000/He基因枪）：**
- 氦气压力：1100 psi
- 真空度：27 inHg
- 靶距：6 cm
- 每个外植体轰击1-2次

**外植体：** 授粉后9-11天幼胚（盾片朝上）或胚性愈伤组织

**筛选：** 轰击后在含Bialaphos（5 mg/L）的培养基上筛选

### 3.8 生根与移栽
**生根诱导（约2-3周）：**
1.  将分化的芽（3-5 cm）切下，转移至RM培养基
2.  28°C，16 h光照/8 h黑暗培养
3.  约2-3周后可见根系生长

**炼苗与移栽：**
1.  打开培养瓶盖，室温炼苗2-3天
2.  用温水洗去根部琼脂
3.  移栽至蛭石:营养土（1:1）混合基质
4.  套袋保湿，28°C，16 h光照培养
5.  2周后去袋，正常管理

**转化效率参考：** Hi-II品系农杆菌法转化效率约10-30%，每次实验建议处理100-200个幼胚。
## Step 4：T0阳性植株鉴定与扩增子测序
### 4.1 T0植株初步鉴定（PCR法）
**目的：** 确认T-DNA整合，排除假阳性
**引物设计：**
（A）T-DNA整合检测：
- 正向引物：位于35S启动子（或根据自身选用启动子设计）
- 反向引物：位于目的基因外显子区域

### 4.2 叶片基因组DNA提取（PCR鉴定）
**材料：** 约100 mg新鲜叶片（或冻干叶片粉末）
**CTAB法提取：**
1.  液氮研磨叶片至细粉
2.  加入700 μL 2× CTAB缓冲液（65°C预热）
3.  65°C水浴30 min，每10 min轻柔混匀
4.  加入等体积氯仿:异戊醇（24:1），充分混匀
5.  12000 rpm离心10 min，取上清
6.  重复氯仿抽提一次
7.  加入2/3体积冷异丙醇，-20°C沉淀30 min
8.  12000 rpm离心10 min，弃上清
9.  70%乙醇洗涤沉淀两次
10. 室温晾干，溶于50 μL TE缓冲液
11. NanoDrop定量：OD₂₆₀/₂₈₀ = 1.8-2.0
以上述基因组DNA为模板，通过PCR扩增对T0转基因植物进行阳性材料鉴定。

**PCR扩增条件**（25 μL体系）**：**
|     |     |
| --- | --- |
| **组分** | **用量** |
| 2× Taq PCR Master Mix | 12.5 μL |
| 正向引物（10 μM） | 1 μL |
| 反向引物（10 μM） | 1 μL |
| 基因组DNA（50-100 ng） | 2 μL |
| ddH₂O | 8.5 μL |

PCR程序：
1.  95°C 3 min
2.  35个循环：95°C 30 sec / 60°C 30 sec / 72°C 1 min
3.  72°C 5 min
4.  4°C 保存

将PCR产物进行琼脂糖凝胶电泳检测。
- 预期条带：仅在转基因植株中出现
## Step 5：T1代筛选——qPCR定量确定目标基因表达水平
### 5.1 T0植株自交
1. 选择编辑阳性T0植株（双等位编辑优先）
2. 套袋自交（防止串粉）：
- - 花粉套袋：雄穗散粉前套纸袋
    - 雌穗套袋：吐丝前套纸袋
    - 人工授粉：收集花粉，授至同株雌穗
3. 收获T1代种子（每株收取30-50粒）
4. 种子干燥后4°C保存

### 5.2 T1代种植与qPCR基因表达分析
**T1代种植：**
- 每个T0株系种植20-30株T1代植株
- 正常温室或田间水培管理

**qPCR基因表达水平检测：**
（A）提取T1代阳性植株Total RNA，并反转录成第一链cDNA。
（B）设计目标基因qPCR定量引物，长度约90~200 bp。
（C）以cDNA为模板，对目标基因进行qPCR定量分析，以ZmActin1或ZmUBQ1基因为内参。
（D）挑选满足实验需求的不同表达水平的株系进行T2代表型鉴定。
（E）表型观察：
- 记录与野生型相比的表型差异
- 农艺性状评估（株高、株型、穗型、粒重等）

### 5.3 株系命名与保存
**命名规则：**[T0株系号]-[T1株系号]- [启动子]-[基因名]
例： T0-3-T1-7-P35S-Zmxxx

**保存：**
1.  收取T1纯合编辑植株种子（T2代种子）
2.  每株系保存至少50粒种子，-20°C干燥保存
3.  建立株系档案（基因型、表型、测序结果）

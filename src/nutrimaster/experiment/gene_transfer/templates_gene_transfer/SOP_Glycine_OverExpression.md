## Step 1：获取目的基因序列
### 1.1 目标
从NCBI获取目的基因CDS编码区序列，用于后续基因表达载体构建及遗传转化。

### 1.2 所需信息
- NCBI GenBank登录号

### 1.3 操作步骤
**（A）获取mRNA/CDS序列**
1.  访问 https://www.ncbi.nlm.nih.gov/nuccore/gene_accession
2.  搜索目的基因，下载CDS编码区序列（FASTA格式）
>_gene_name___gene_accession_
_gene_sequence_
>_gene_name___gene_accession_up2k
_gene_sequence_up2k_
>_gene_name___gene_accession_down2k
_gene_sequence_down2k_


**（B）大豆基因组参考**
- 参考基因组：Wm82.a4.v1（SoyBase: https://www.soybase.org）
- 若为多拷贝基因（大豆为异源四倍体），需检索所有同源拷贝
**注意：**大豆基因组存在大量重复序列，同源基因可能存在功能冗余。

## Step 2：单基因表达载体构建（常用于单基因表达验证）
2.1 载体选择：推荐pCAMBIA系列表达载体，CaMV35启动子，为植物常用表达载体。
2.2 标签选择：根据实验需求添加eGFP、GUS、3xflag等。
2.3 载体构建流程：
（1） 基因克隆及PCR产物纯化，参考胶回收纯化试剂盒说明书进行；
（2）pCAMBIA系列载体单酶切线性化，参考单酶切说明书进行；
（3）一步克隆法构建重组表达载体，参考一步克隆试剂盒说明书进行；
（4） 转化_E.coli_感受态细胞；
（5）单克隆鉴定及测序；
（6）质粒提取，用于农杆菌感受态细胞转化。

### 2.2 GoldenBraid2.0多基因载体组装流程
#### 2.2.1 表达元件克隆与pUPD2入门载体构建
启动子选择及pUPD2入门载体构建

若需要种子特异表达，推荐Cnl1, Cnl2, FAE1, Napin, Gm7a, 11s GY1, Oleosin等种子特异表达启动子。

（1）启动子构建pUPD2入门载体oligo设计：

（3）终止子选择及pUPD2入门载体构建

#### 2.2.4 蓝白斑筛选方法
（1）X-gal（20 mg/ml）用二甲基亚砜（DMSO）或二甲基甲酰胺（DMF）溶解，-20 ℃避光保存；
（2）IPTG（ 24mg/ml, 100 mM），用ddH2O溶解，过滤除菌，-20 ℃保存；
（3）在100 mL的LB固体培养基中，分别加入200 μL X-gal，100 μL IPTG，和相应浓度抗生素，制成X-gal、IPTG、抗生素平板培养基备用。
**注：pUPD2入门载体为氯霉素抗性，pDGB3_α载体为卡那霉素抗性，pDGB3_Ω载体为壮观霉素抗性。所有连接载体通过蓝白斑筛选，挑取白色克隆进行菌落鉴定。**

## Step 3：毛状根快速验证
### 3.1 原理
利用发根农杆菌（Agrobacterium rhizogenes K599）介导的毛状根转化系统，在2-3周内快速评估目标基因功能，避免耗时的稳定转化。

### 3.2 材料准备
**菌株：** A. rhizogenes K599（含过表达载体）  
**大豆品种：** Williams 82 或 Jack（转化效率较高）  
**种子处理：** 70%乙醇表面消毒30 sec → 10% NaClO消毒10 min → 无菌水洗涤5次

### 3.3 发根农杆菌制备
1. 将含给过表达载体的K599菌株划线至含相应抗生素的YEB平板
- 利福平（Rifampicin）：25 μg/mL（K599菌株自身抗性）
- 载体抗生素（如卡那霉素50 μg/mL）
2. 28°C培养2天
3. 挑取单菌落接种至5 mL YEB液体培养基（含相应抗生素）
4. 28°C，200 rpm振荡培养过夜
5. 转接至50 mL YEB，培养至OD600 = 0.6-0.8
6. 4000 rpm离心10 min，弃上清
7. 用1/2 MS液体培养基（不含抗生素）重悬至OD600 = 0.5

### 3.4 大豆毛状根转化操作
**参考方案：** Cheng et al. (2021) [6] 和 Kong et al. (2023) [1]
Day 0 - 种子萌发：
1. 大豆种子用无菌水浸泡4-6 h
2. 播种至1/2 MS固体培养基（含0.8%琼脂）
3. 25°C暗培养2天，待胚根长至1-2 cm

Day 2 - 接种：
1. 取萌发种子，在超净工作台中用无菌手术刀切除胚根（保留下胚轴）
2. 将下胚轴切口浸入菌液（OD600 = 0.5）中，室温浸染15-30 min
- 可用注射器针头在下胚轴上轻划数道伤口，提高转化效率
3. 用无菌滤纸吸干多余菌液
4. 将接种材料平放于1/2 MS固体培养基（含200 μM乙酰丁香酮，AS）
5. 25°C暗培养3天（共培养）

Day 5 - 转移至筛选培养基：
1. 将材料转移至含抑菌剂的1/2 MS培养基：
- 头孢噻肟（Cefotaxime）：500 mg/L（抑制农杆菌）
- 潮霉素（Hygromycin）：25 mg/L（筛选阳性毛状根，若载体含Hyg抗性）
- 或：GFP荧光筛选（若载体含GFP报告基因）
2. 25°C，16 h光照/8 h黑暗培养

Day 14-21 - 毛状根生长：
1. 观察下胚轴切口处毛状根生长情况
2. 阳性毛状根特征：
- 生长旺盛，多分枝，无向地性
- 在潮霉素培养基上正常生长（阴性根生长受抑）
- 若含GFP：荧光显微镜下可见绿色荧光
3. 每株保留3-5条独立毛状根（来自不同转化事件）
4. 继续培养至毛状根长度达3-5 cm（约7-14天）

## Step 4：毛状根基因组提取与PCR鉴定
### 4.1 基因组DNA提取
**材料：** 约100 mg新鲜毛状根组织
**CTAB法提取：**
1. 液氮研磨毛状根至细粉
2. 加入700 μL 2× CTAB缓冲液（65°C预热）
- 2× CTAB：2% CTAB, 100 mM Tris-HCl pH8.0, 20 mM EDTA, 1.4 M NaCl
3. 65°C水浴30 min，每10 min轻柔混匀
4. 加入等体积氯仿:异戊醇（24:1），充分混匀
5. 12000 rpm离心10 min，取上清
6. 重复氯仿抽提一次
7. 加入2/3体积冷异丙醇，-20°C沉淀30 min
8. 12000 rpm离心10 min，弃上清
9. 70%乙醇洗涤沉淀两次
10. 室温晾干，溶于50 μL TE缓冲液
11. NanoDrop定量：OD260/280 = 1.8-2.0，OD260/230 > 1.8
12. 琼脂糖凝胶电泳确认DNA完整性（主带清晰，无明显降解）

**或使用商业试剂盒：** CTAB法适合植物组织，也可使用Qiagen DNeasy Plant Mini Kit（操作更简便）。
### 4.2 PCR鉴定引物设计
• 正向引物：位于35S启动子（或根据自身选用启动子设计）
• 反向引物：位于目的基因外显子区域
以上述基因组DNA为模板，通过PCR扩增对T0转基因植物进行阳性材料鉴定。

**PCR扩增条件**（25 μL体系）**：**
|     |     |
| --- | --- |
| **组分** | **用量** |
| 2× Taq PCR Master Mix | 12.5 μL |
| 正向引物（10 μM） | 1 μL |
| 反向引物（10 μM） | 1 μL |
| 基因组DNA（50-100 ng） | 2 μL |
| ddH₂O | 8.5 μL |

PCR程序：
- 95°C 3 min
- 35个循环：95°C 30 sec / 60°C 30 sec / 72°C 1 min
- 72°C 5 min
- 4°C 保存
将PCR产物进行琼脂糖凝胶电泳检测。

### 4.3 数据分析
- 对鉴定阳性的毛状根提取RNA进行qPCR基因表达分析。
- 根据实验目的，若研究转录因子的表达调控，进一步对潜在靶基因进行qPCR定量分析。
- 根据实验目的，若研究代谢物合成与调控，提取化合物进行uPLC或质谱检测。
- 根据实验目的，若研究非生物胁迫，对毛状根进行胁迫处理，观察并统计表型，并记录相关生理指标。

## Step 5：大豆稳定遗传转化（子叶节法）
### 5.1 原理
利用根癌农杆菌（A. tumefaciens EHA105）介导的子叶节转化法，是大豆稳定转化的经典方法，转化效率约1-5% [19, 23, 27]。

### 5.2 材料准备
**菌株：** A. tumefaciens EHA105（含过表达载体）  
**大豆品种：** Williams 82（标准品种，转化效率有保障）  
**种子：** 饱满、无病虫害，4°C干燥保存

### 5.3 培养基配方
|     |     |     |
| --- | --- | --- |
| **培养基** | **成分** | **用途** |
| 萌发培养基（GM） | B5盐 + 3% 蔗糖 + 0.8% 琼脂，pH 5.8 | 种子萌发 |
| 共培养培养基（CCM） | B5盐 + 3% 蔗糖 + 1 mg/L 6-BA + 200 μM AS + 0.8% 琼脂，pH 5.4 | 农杆菌侵染后共培养 |
| 芽诱导培养基（SIM） | B5盐 + 3% 蔗糖 + 1.67 mg/L 6-BA + 500 mg/L Cefotaxime + 25 mg/L Hygromycin + 0.8% 琼脂，pH 5.8 | 芽诱导与筛选 |
| 芽伸长培养基（SEM） | MS盐 + 3% 蔗糖 + 0.5 mg/L GA₃ + 500 mg/L Cefotaxime + 25 mg/L Hygromycin + 0.8% 琼脂，pH 5.8 | 芽伸长 |
| 生根培养基（RM） | 1/2 MS盐 + 2% 蔗糖 + 1 mg/L IBA + 0.8% 琼脂，pH 5.8 | 生根  |

### 5.4 农杆菌制备
1. 将含过表达载体的EHA105划线至含抗生素的YEB平板
- 利福平：25 μg/mL
- 载体抗生素（如卡那霉素：50 μg/mL）
2. 28°C培养2天
3. 挑单菌落接种至5 mL YEB液体培养基，28°C过夜
4. 转接至50 mL YEB，培养至OD600 = 0.6-0.8（约4-6 h）
5. 4000 rpm离心10 min，弃上清
6. 用侵染培养基（B5液体 + 200 μM AS）重悬至OD600= 0.5-0.6
7. 室温静置30 min（活化vir基因）

### 5.5 外植体制备与侵染
Day -5 至 Day 0 - 种子萌发：
1. 大豆种子表面消毒：
- 70%乙醇：1 min
- 50% NaClO（含0.1% Tween-20）：15 min
- 无菌水洗涤5次
2. 播种至GM培养基，25°C暗培养5-6天
3. 待子叶展开，胚轴长约3-4 cm

Day 0 - 外植体制备与侵染：
1. 在超净工作台中取出萌发种苗
2. 切除根部，保留子叶节（含腋芽）
3. 用无菌手术刀纵向切开子叶节，分为两半（每半含一片子叶和腋芽）
4. 用解剖针在腋芽处轻划5-8道伤口（深约0.5 mm）
5. 将外植体浸入菌液（OD600 = 0.5-0.6）中，室温侵染30 min，轻柔摇动
6. 用无菌滤纸吸干多余菌液
7. 将外植体切口朝下放置于CCM培养基
8. 25°C，16 h光照/8 h黑暗，共培养3天

### 5.6 芽诱导与筛选
Day 3 - 转移至筛选培养基：
1. 用无菌水洗涤外植体3次（去除农杆菌）
2. 用含500 mg/L Cefotaxime的无菌水再洗涤一次
3. 用无菌滤纸吸干，转移至SIM培养基
4. 25°C，16 h光照/8 h黑暗培养
每2周继代一次（转移至新鲜SIM培养基）：
- 第1-2次继代：SIM（含Hygromycin 25 mg/L）
- 观察：阳性外植体在潮霉素压力下仍可诱导绿色芽点
- 阴性外植体：芽点黄化、死亡

Day 21-35 - 芽伸长：
1. 当芽长至0.5-1 cm时，切下转移至SEM培养基
2. 25°C，16 h光照/8 h黑暗培养2-3周
3. 每2周继代一次
4. 目标：芽伸长至3-5 cm

### 5.7 生根与移栽
生根诱导（约2-3周）：
1. 将伸长的芽（3-5 cm）切下，基部切口斜切
2. 转移至RM培养基（含IBA 1 mg/L）
3. 25°C，16 h光照/8 h黑暗培养
4. 约2-3周后可见白色根系生长

炼苗与移栽：
1. 打开培养瓶盖，室温炼苗2-3天
2. 用温水轻柔洗去根部琼脂
3. 移栽至蛭石:珍珠岩:营养土（1:1:2）混合基质
4. 套袋保湿，25°C，16 h光照培养
5. 每天喷水保湿，逐渐减少保湿频率
6. 2周后去袋，正常管理
7. 移栽成活后，取叶片进行PCR鉴定（T-DNA整合）

**转化效率参考：** Williams 82品种子叶节法转化效率约1-5%，每次实验建议处理100-200个外植体 [23, 27]。

## Step 6：T0阳性植株鉴定与扩增子测序
**6.1 T0植株初步鉴定（PCR法）**
**目的：** 确认T-DNA整合，排除假阳性
**引物设计：**
- 正向引物：位于35S启动子（或根据自身选用启动子设计）
- 反向引物：位于目的基因外显子区域

**6.2 叶片基因组DNA提取（PCR鉴定）**
**材料：** 约100 mg新鲜叶片（或冻干叶片粉末）
**CTAB法提取：**
1.  液氮研磨叶片至细粉
2.  加入700 μL 2× CTAB缓冲液（65°C预热）
3.  65°C水浴30 min，每10 min轻柔混匀
4.  加入等体积氯仿:异戊醇（24:1），充分混匀
5.  12000 rpm离心10 min，取上清
6.  重复氯仿抽提一次
7.  加入2/3体积冷异丙醇，-20°C沉淀30 min
8.  12000 rpm离心10 min，弃上清
9.  70%乙醇洗涤沉淀两次
10. 室温晾干，溶于50 μL TE缓冲液
11. NanoDrop定量：OD₂₆₀/₂₈₀ = 1.8-2.0
以上述基因组DNA为模板，通过PCR扩增对T0转基因植物进行阳性材料鉴定。

**PCR扩增条件**（25 μL体系）**：**
|     |     |
| --- | --- |
| **组分** | **用量** |
| 2× Taq PCR Master Mix | 12.5 μL |
| 正向引物（10 μM） | 1 μL |
| 反向引物（10 μM） | 1 μL |
| 基因组DNA（50-100 ng） | 2 μL |
| ddH₂O | 8.5 μL |

PCR程序：
- 95°C 3 min
- 35个循环：95°C 30 sec / 60°C 30 sec / 72°C 1 min
- 72°C 5 min
- 4°C 保存

将PCR产物进行琼脂糖凝胶电泳检测。
- 预期条带：仅在转基因植株中出现

## Step 7：T1代筛选——qPCR定量确定目标基因表达水平
### 7.1 T0植株自交
1. 选择PCR鉴定阳性T0植株
2. 正常播种及田间水培管理，收获T0代种子
3. 种子干燥后4°C保存

**7.2** **T1代种植与qPCR基因表达分析**
**qPCR基因表达水平检测：**
（A）提取T1代阳性植株Total RNA，并反转录成第一链cDNA。
（B）设计目标基因qPCR定量引物，长度约90~200 bp。
（C）以cDNA为模板，对目标基因进行qPCR定量分析，以OsActin1或OsUBQ5基因为内参。
（D）挑选满足实验需求的不同表达水平的株系进行T2代表型鉴定。
（E）表型观察：
- 记录与野生型相比的表型差异
- 农艺性状评估（株高、株型、粒重等）

**7.3 株系命名与保存**
**命名规则：**[T0株系号]-[T1株系号]- [启动子]-[基因名]
例： T0-3-T1-7-P35S-Gmxxx

**保存：**
1.  收取T1纯合编辑植株种子（T2代种子）
2.  每株系保存至少50粒种子，-20°C干燥保存
3.  建立株系档案（基因型、表型、测序结果）
